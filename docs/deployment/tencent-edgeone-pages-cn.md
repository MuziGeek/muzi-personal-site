# Muzi 个人网站：中国大陆部署操作手册

本文用于把 Muzi Astro 静态网站部署到腾讯云 EdgeOne Pages，并以
`www.easymuzi.cn` 面向中国大陆访客提供服务。

> 目标架构：GitHub 私有仓库 → EdgeOne Pages 自动构建 → 中国大陆可用区 →
> `www.easymuzi.cn` → HTTPS。

## 1. 先理解最终选择

主要访客在中国大陆时，正式环境选择 **中国大陆可用区**。该区域的自定义域名必须先完成
ICP备案。不要把“全球可用区（不含中国大陆）”作为正式方案；它适合备案前的构建验证，
不能提供同等的大陆节点体验。

这个项目是纯静态 Astro 网站，不需要云服务器运行 Node.js，也不需要数据库、容器或
Pages Functions。Node.js 只在 EdgeOne 的构建阶段使用。

## 2. 上线前准备清单

开始备案前准备以下内容：

- 腾讯云个人账号，并完成与备案主体一致的实名认证。
- 已完成实名认证的 `easymuzi.cn`。域名实名认证信息应与备案主体一致。
- 域名实名认证完成至少 3 个自然日；非腾讯云注册域名按控制台提示等待信息同步。
- 可接收短信的中国大陆手机号。
- 身份证件和符合所在省通信管理局要求的资料。
- 腾讯云备案控制台能够识别的备案云资源。
- 已推送至 GitHub 的站点源码仓库。

### 2.1 备案资源的选择

EdgeOne Pages 要求大陆域名已经备案，但 Pages 是否直接显示为可用备案资源，应以当前账号的
备案控制台为准。若控制台没有可选择的 Pages 资源，最直接的方案是购买符合备案条件的中国大陆
轻量应用服务器：

- 地域：中国大陆。
- 计费：包年包月。
- 累计购买时长：至少 3 个月。
- 备案期间剩余有效期：至少 1 个月。
- 具备公网 IP。

个人实名认证账号不能自行生成备案授权码，不要购买或接受来源不明的授权码。

购买前再次查看腾讯云备案控制台的“可备案资源”，避免只为了备案买错产品。

## 3. GitHub 仓库准备

建议源码仓库保持为 **Private**：网站可以正常公开部署，同时避免在字体授权范围尚未确认时
公开再分发嵌入字体。

远程仓库应至少包含：

- `src/`：页面、组件、内容和样式。
- `public/`：站点图片、视频、图标和字体子集。
- `package.json` 与 `package-lock.json`。
- `astro.config.mjs` 与 `tsconfig.json`。

不应提交：

- `node_modules/`
- `dist/`
- `.astro/`
- `.env*`
- `.codex-review/`
- 本地设计工具输出和 Python 缓存

每次正式部署前，在本地运行：

```bash
npm ci
npm test
npm run check
npm run build
```

全部通过后再推送生产分支。

## 4. 提交个人 ICP 备案

### 4.1 进入备案系统

1. 登录腾讯云控制台。
2. 打开“ICP备案”。
3. 首次备案选择“首次备案”；已有主体备案时选择“新增网站/服务”。
4. 按控制台要求授权腾讯云读取账号中的备案资源。

### 4.2 填写主体信息

主体性质选择“个人”，证件、地址、手机号和域名实名信息保持一致。

个人网站名称和备注按所在省通信管理局的规则填写，不要使用企业、机构、交易平台或新闻媒体
等容易造成经营性误解的名称。网站用途可以如实描述为：

> 个人作品、开源实践、学习笔记和创作记录展示，不提供用户注册、交易、论坛、新闻发布或经营性服务。

不要为了通过审核填写与实际网站不一致的信息。

### 4.3 填写网站信息

- 网站域名：`easymuzi.cn`（备案通常以主域名为单位）。
- 服务内容：个人非经营性展示。
- 语言：中文。
- 前置审批：当前个人作品网站通常不涉及；最终以控制台和所在省管局要求为准。

当前站点没有登录、评论、支付、论坛、内容投稿和数据库，保持这个边界有利于备案信息与实际
服务一致。

### 4.4 提交与核验

1. 完成腾讯云初审和资料补充。
2. 收到工信部短信后，在规定时间内完成短信核验。
3. 等待省通信管理局审核。
4. 备案审核期间，不要提前把 `easymuzi.cn` 或 `www.easymuzi.cn` 指向公开网站。

备案期间可以使用 EdgeOne 控制台生成的短期预览链接检查构建，但不要把它当成正式网址。

## 5. 创建 EdgeOne Pages 项目

ICP备案通过后开始正式部署。

### 5.1 导入仓库

1. 打开腾讯云 EdgeOne Pages 控制台。
2. 选择“创建项目”并连接 GitHub。
3. 只授权需要部署的 `MuziGeek/muzi-personal-site` 私有仓库。
4. 选择 `main` 为生产分支。

### 5.2 构建配置

使用以下配置：

| 配置项 | 值 |
| --- | --- |
| 框架预设 | Astro |
| 根目录 | `./` |
| Node.js | `22.17.1` |
| 安装命令 | `npm ci` |
| 构建命令 | `npm run build` |
| 输出目录 | `dist` |
| 生产分支 | `main` |

项目的 `package.json` 要求 Node.js `>=22.12.0`，因此不要选择 `22.11.0`。

### 5.3 首次构建验收

第一次部署结束后检查构建日志：

- 依赖安装成功。
- `astro build` 成功。
- 输出目录识别为 `dist`。
- 生成 7 个静态页面。
- 没有上传 `.env`、源地图或本地缓存。

大陆/全球区域的 Pages 平台域名可能只能通过短期预览链接访问，这是平台的合规限制；正式访问
必须绑定已备案的自定义域名。

## 6. 选择加速区域

进入 Pages 项目设置，把加速区域选择为：

> **中国大陆可用区**

如果未来海外访问量明显增加，并且套餐与成本可以接受，再评估“全球可用区（含中国大陆）”。
不要选择“全球可用区（不含中国大陆）”作为当前正式环境。

## 7. 绑定域名且不影响邮箱

网站先使用 `www.easymuzi.cn`。这样可以把网站 DNS 与 `mz@easymuzi.cn` 的邮件配置隔离。

### 7.1 添加自定义域名

1. 在 Pages 项目中打开“域名管理”。
2. 添加 `www.easymuzi.cn`。
3. 复制 EdgeOne 给出的 CNAME 目标值。
4. 到当前 DNS 服务商添加记录：

| 类型 | 主机记录 | 记录值 |
| --- | --- | --- |
| CNAME | `www` | EdgeOne 控制台提供的目标值 |

### 7.2 邮箱保护红线

添加网站记录时不要删除或覆盖以下类型的记录：

- MX
- SPF 对应的 TXT
- DKIM 对应的 TXT/CNAME
- DMARC 对应的 TXT
- 邮箱服务商要求的验证记录

修改前先导出或截图完整 DNS 记录。若修改后 `mz@easymuzi.cn` 收发异常，立即恢复 DNS，网站部署
可以稍后继续。

### 7.3 HTTPS

等待域名验证通过和证书签发，然后：

- 开启 HTTPS。
- 开启 HTTP 自动跳转 HTTPS。
- 确认浏览器证书域名包含 `www.easymuzi.cn`。

暂时不要急于改根域名。待 `www` 稳定后，再将 `easymuzi.cn` 通过 EdgeOne 重定向至
`https://www.easymuzi.cn`，仍不得改动邮件记录。

## 8. 在网站页脚添加备案信息

ICP备案通过后，在 `src/components/SiteFooter.astro` 中增加工信部备案号链接：

- 文本使用管局下发的完整备案号。
- 链接指向 `https://beian.miit.gov.cn/`。
- 不要填写示例号或尚未下发的号码。

修改后重新提交并推送 `main`，确认 EdgeOne 自动产生新的生产部署。

## 9. 上线后办理公安联网备案

网站正式开通后 30 日内，登录全国互联网安全管理服务平台：

<https://beian.mps.gov.cn/>

按平台要求提交个人网站备案。审核通过后：

1. 下载公安备案图标。
2. 将公安备案号及图标放到网站页脚。
3. 链接使用平台提供的备案详情地址。
4. 再次构建并部署。

## 10. 正式验收

### 10.1 页面检查

至少检查：

- `/`
- `/works/`
- `/open-source/`
- `/about/`
- `/notes/`
- `/bookmarks/`
- `/404.html`

### 10.2 终端与网络检查

- 手机流量和家庭宽带分别访问。
- 检查中国移动、中国联通、中国电信网络中的至少两个。
- 检查 HTTPS、证书、字体、视频、图片和页面动效。
- 检查 390、768、1024、1280 和 1440px 布局。
- 检查浏览器控制台没有资源 404 或运行错误。
- 检查 `mz@easymuzi.cn` 仍能正常收信和发信。

### 10.3 SEO 与站点信息

- 页面标题和描述正确。
- `favicon.ico` 和 `favicon.svg` 可访问。
- Open Graph 图片可访问。
- 备案号在页脚清晰可见。
- 不公开本机路径、临时预览地址、密钥或构建日志。

## 11. 更新与回滚

日常发布流程：

1. 在本地完成修改。
2. 运行测试、Astro 检查和静态构建。
3. 提交并推送 `main`。
4. 等待 EdgeOne 自动构建。
5. 先检查新部署，再确认生产域名。

如果新版本有问题：

1. 在 EdgeOne 部署记录中恢复上一个成功版本，或在 Git 中回退有问题的提交。
2. 不要删除 Pages 项目、备案记录或 DNS 邮件记录。
3. 如果只是域名异常，将 `www` 的 CNAME 恢复到上一条确认可用的值。

## 12. 常见问题

### Pages 地址返回 401

平台项目域名或部署域名可能受短期预览限制。使用控制台生成的预览链接验证，正式环境绑定已备案
的自定义域名。

### 无法选择中国大陆可用区

确认域名已在工信部备案系统可查询，备案主体状态有效，并等待腾讯云同步。仍无法选择时，提交
腾讯云工单，不要反复删除并重新添加域名。

### 构建提示 Node.js 版本不满足

在项目设置中选择 `22.17.1`，然后重新部署。

### 构建成功但页面 404

确认输出目录是 `dist`，并检查构建产物根目录中存在 `index.html`。

### 邮箱突然无法收发

立即检查 MX、SPF、DKIM 和 DMARC。网站只需要新增 `www` 的 CNAME，不需要删除邮箱记录。
