# PFanHuTuTi webfont subset

`pfan-hutu-subset.woff2` is a page-text subset derived from the site owner's locally installed `PFanHuTuTi-Regular.ttf`.

- The subset is generated by `scripts/subset-display-font.py` from characters currently used under `src/`.
- The original 10.5 MB TTF is not stored in this repository.
- The site owner confirmed direct embedding for this personal website. This note does not grant downstream redistribution rights; re-check the original font terms before reusing the file elsewhere.
- Public font information referenced during implementation: <https://www.aitesu.com/show-775.html>
